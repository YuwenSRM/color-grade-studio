# 图片库

图片库将原始文件与手动导入文件分开保存，图片元数据、审核状态和实际存储路径保存在
`../data/landscape.db`。

| 目录         | 用途                         | 使用方式                                   |
| ------------ | ---------------------------- | ------------------------------------------ |
| `originals/` | 网页上传与调色成片的原始文件 | 由服务自动写入，请勿手动修改文件名         |
| `imports/`   | 手动导入的图片               | 将拥有合法使用权的图片复制到这里或其子目录 |

支持 JPG、JPEG、PNG、WebP、GIF、AVIF。手动导入的图片会在打开图库、审核页或后台时
自动登记到数据库。网页上传的图片会生成 UUID 文件名，原文件名仅保存在数据库元数据中，
避免同名文件互相覆盖。

旧版本存放在项目根目录 `uploads/` 的图片会继续正常显示；它们保留为兼容数据，不需要
手动移动。新上传内容会保存到 `originals/`。
