# 使用说明

## 启动本地项目

安装 Node.js 18 或更高版本，并确保 SQLite 可执行程序可用。复制 `.env.example` 为 `.env`，按需设置配置后双击 `start-server.bat`，或在项目目录运行 `node serve.js`。默认地址为 `http://127.0.0.1:4173/login.html`。

启动器会复用可用的本地服务。服务日志写入 `data/startup.log`；使用 `start-server.bat --no-open` 可以只验证启动，不打开浏览器。修改 `serve.js` 或后端配置后需要重启服务。

未设置 `SQLITE_PATH` 时，项目会依次查找 `tools/sqlite3.exe` 和系统 `PATH` 中的 `sqlite3`。端口和主机由 `PORT`、`HOST` 配置；本地部署只接受 `127.0.0.1` 或 `localhost`。

## 页面与权限

| 页面                  | 用途                       | 访问权限                                   |
| --------------------- | -------------------------- | ------------------------------------------ |
| `real-landscape.html` | 图片库、大图查看、上传入口 | 所有人可浏览；用户和管理员可上传           |
| `color-grade.html`    | 调色、裁切、滤镜和导出     | 所有人可本地调色；上传成片需要用户或管理员 |
| `login.html`          | 登录与游客浏览入口         | 所有人                                     |
| `audit.html`          | 图片审核、质量评分和备注   | 管理员                                     |
| `admin.html`          | 数据统计与账号管理         | 管理员                                     |

游客无需密码且仅能浏览。普通用户可以上传。管理员拥有审核、统计和账号管理权限；服务端负责最终的角色校验。

首次启动时，若数据库没有账户且 `.env` 配置了 `ADMIN_USERNAME` 与 `ADMIN_PASSWORD`，服务会创建管理员。创建后删除或更换该配置不会修改既有账户。

## 图片和数据

- `data/landscape.db` 保存账户、图片元数据和审核结果。
- `image-library/originals/` 保存从网页和调色台上传的原图。
- `image-library/imports/` 用于手动放入待同步的图片。
- `uploads/` 是旧上传文件的兼容目录，已有记录仍会读取。

这些目录属于本地运行数据，不应提交到 Git。升级、清理或迁移机器前应先备份数据库和图片目录。

## 调色与导出

调色工作台在当前浏览器会话中保留原始图片，用于以原图重新渲染导出。裁切和调色参数不会覆盖本地原文件。

导出规格包括原图、高清、标准、网页和预览：高清优先 WebP 质量 96；标准长边不超过 3000px；网页不超过 2048px；预览不超过 1100px。浏览器不支持 WebP 时会回退为 PNG。

独立版中，用户导入的滤镜、收藏、主题和语言保存于浏览器本机数据。清理站点数据、切换浏览器或改变端口前，请使用调色台中的“备份我的滤镜”；恢复会先校验备份文件。

## 语言与主题

中文为默认界面语言。调色工作台的英文翻译集中维护在 `assets/locales/color-grade-en-US.js`。语言选择会同步到同源的其他标签页；主题和语言也会作为浏览器本地偏好保存。
