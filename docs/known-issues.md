# 已知问题

本文件汇总仍需处理的运行、权限、性能和调色工作台问题。

## 高优先级

| 问题                                           | 影响                                | 建议                                                     |
| ---------------------------------------------- | ----------------------------------- | -------------------------------------------------------- |
| 静态资源路由可读取项目根目录内容               | 可能暴露 `.env`、数据库、日志或源码 | 改为静态资源白名单，并将运行数据移出可公开路径           |
| 匿名图库查询返回全部图片记录，审核过滤依赖前端 | 未审核内容可能被访问                | 服务端仅返回已通过内容，并使图片文件访问遵循同一权限规则 |

## 中优先级

| 问题                                               | 影响                                   | 建议                                                     |
| -------------------------------------------------- | -------------------------------------- | -------------------------------------------------------- |
| 大于 16MB 的上传会直接断开，multipart 全量缓存     | 用户没有明确错误提示，服务内存压力较大 | 返回 413，限制像素和文件大小，并改用流式上传             |
| 图库和统计请求重复遍历目录、逐图启动 SQLite 子进程 | 大图库或慢磁盘下可能阻塞服务           | 使用批量事务、增量扫描或缓存，并评估受维护的 SQLite 驱动 |
| 原图导出缺少总像素上限                             | 超大图可能内存不足                     | 按实际输出宽高限制总像素，必要时用 Worker 或分块渲染     |
| WebP 回退只依赖异常                                | PNG 内容可能被标记为 WebP              | 根据导出 Blob 的 `type` 设置 MIME 和扩展名               |
| 导出直接读取实时控件和裁切框                       | 未应用编辑可能与预览、上传结果不一致   | 建立已应用参数快照，统一预览、应用、上传和导出契约       |
| 当前 Node.js 18.19.0 已结束官方维护                | 维护与安全风险                         | 备份数据后迁移至受支持的 LTS，并完成回归测试             |

## 低优先级

| 问题                                                                   | 建议                               |
| ---------------------------------------------------------------------- | ---------------------------------- |
| 自定义下拉框关闭时未统一更新 `aria-expanded`，键盘打开后焦点不进入选项 | 统一开关入口并补充键盘可访问性测试 |

## 调色工作台反馈

- 基础调色高光的加减方向与显示预期不一致。
- 三段色彩分级数值仅在点开后显示；交互和数值呈现需要参考专业调色工具完善。
- 夜间模式仍有局部框架未适配。
- 裁切比例需要补充 `2.35:1` 电影画幅。
- 预览区需要提供原图与调色后、左右或上下分屏等对比视图。

这些问题尚未在本阶段修复。变更调色逻辑或页面前，应先建立截图和操作回归基线，并覆盖中英文、明暗主题、桌面与移动布局。
