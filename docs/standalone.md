# 调色台使用说明

## 启动

1. 将整个独立包解压到本机文件夹，不要只复制其中某一个文件。
2. 双击 `ColorGradeStudio.vbs`。
3. 浏览器会自动打开本机调色台；第一次启动可能需要短暂等待。

无需安装 Node.js，也不需要联网。

## 遇到启动问题

双击 `ColorGradeStudio.cmd`，在显示的命令窗口中查看错误信息。不要删除、改名或单独移动 `app/`、
`ColorGradeStudio.ps1`、`MANIFEST.json` 等文件。

## 停止服务

关闭浏览器后，如需停止本地调色服务，在独立包文件夹的资源管理器地址栏输入 `cmd` 并按 Enter，
再执行：

```bat
ColorGradeStudio.cmd --stop
```

## 本地数据

图片只在当前浏览器会话中处理。用户导入的滤镜、收藏、主题和语言保存在该浏览器的本机数据中；清除
浏览器站点数据前，请先在调色台内使用“备份我的滤镜”。
